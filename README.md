# 再弹一条 · 深海低语

一个适配手机的弹珠肉鸽小游戏。拖动瞄准、松手发射，把小鱼送入底部倍率鱼缸。

[在线试玩](https://stevenyang723.github.io/fish-break/)

## 2.1 禁忌契约平衡

所有克苏鲁遗物都有独立的机械代价。三选一卡片红色栏显示获得后的总代价，侵蚀面板可查看已签下的全部契约，触发供养、遗忘、再生和献祭时会显示对应提示。

| 遗物 | 代价 |
| --- | --- |
| 触须共生 | 每级直接撞击气泡得分降低 15%，间接得分保留 |
| 深渊之眼 | 每级中央鱼缸缩窄 18 像素，可用加宽遗物补偿 |
| 不可名状之卵 | 每次成功孵化，消耗主鱼当前气泡分的 40%；达到分裂上限不收费 |
| 血潮契约 | 每级少一发，最低剩一发；第二级不再受到两发保底保护 |
| 黑潮回响 | 每级降低未重生气泡价值 15%；幽灵保留原值 75% |
| 虚空吞口 | 中央缩窄 28 像素，最外侧鱼缸降至 ×0.5；保底只补偿侧缸倍率 |
| 群星归位 | 每次先永久献祭最近 3 / 4 颗气泡，不计分、不触发效果、不能再生 |
| 梦魇鳃 | 成功召唤时清空主鱼当前气泡分，已结算分数保留 |
| 深潜者再生 | 技能返弹消耗当前主鱼气泡分的 50%；回音航线的免费返弹优先 |

各项代价随持有的遗物叠加。普通遗物可以补偿部分风险；关卡目标仍基于原始地图奖励，不会因负面效果而自动降低。旧存档继续保留关卡、遗物和累计分数，并同步新发射次数限制。

## 2.0 更新

- 5 个海域、10 层下潜：日光浅滩 → 荧光海林 → 暮光裂谷 → 无光深渊 → 拉莱耶遗城。通关后可继续无尽下潜。
- 4 种布局、5 条随机航线：繁生珊瑚、珍珠矿脉、湍流航道、回音海沟、古神祭场。每次过关先选下一条航线，再挑遗物。
- 地图基础气泡数由 42 增至 90，珍珠矿脉额外增加 8 颗；单颗基础分从 10 增至 34。珍珠为 4 倍基础分，爆裂泡炸开邻近得分点。目标根据本层地图奖励及深度计算，倍率和技能会继续提高收益。
- 24 种可组合遗物，开局三选一，每轮有 3 次重抽。其中 9 种克苏鲁遗物：触须、凝视、幼体孵化、血潮献祭、幽灵再生、虚空吞口、群星仪式、梦魇和深潜者再生。
- 侵蚀度达到 1 / 3 / 6 / 9，鱼的触须、额外眼睛、古神背景、拖尾、界面配色逐级异化。部分技能有明确代价，可用其他遗物弥补。
- 新增洋流、热泉、漩涡、祭坛，保留弹簧、转轮和传送门。机关随深度逐步解锁。
- 本机自动存档、旧版进度迁移、键盘操作、可选合成音效和减少动态效果支持。

## 本地运行

需要 Node.js 18 或更高版本，无第三方依赖。

```sh
npm start
# 打开 http://127.0.0.1:4317
npm test
```

纯 HTML/CSS/Canvas/JavaScript。静态文件直接放在 main 分支根目录，GitHub Pages 使用 Deploy from a branch → main → / (root)，由 .nojekyll 保留直接静态发布。

## 验证

23 项引擎测试覆盖 400 张随机地图的奖励增长、所有机关的结算时限、技能组合、升级上限、路线与重抽、分裂数量、再生限制、各项代价的计费时机、补偿效果、存档一致性与旧版迁移。2.1 另用 900 组成对固定地图模拟对比调整前后收益，并检查桌面与手机界面。
