# 再弹一条 · 深海低语

一个适配手机的弹珠肉鸽小游戏。拖动瞄准、松手发射，把小鱼送入底部倍率鱼缸。

[在线试玩](https://stevenyang723.github.io/fish-break/)

## 2.2 累积侵蚀阶梯

每获得一次克苏鲁升级，侵蚀增加 1 层，重复升级同一技能也计数。所有技能共享以下负面阶梯，与技能种类无关；每层新增效果，前面的负面全部保留。普通升级不增加侵蚀。三选一卡片预览下一层代价，侵蚀面板列出已生效与待解锁效果。

| 层数 | 负面 | 效果 |
| --- | --- | --- |
| 1 | 缸口收缩 | 中央高倍率鱼缸缩窄 14 像素；加宽遗物仍可补偿。 |
| 2 | 边缘失宠 | 最外侧两只鱼缸倍率减半：通常为 ×0.5；保底升级后为 ×1。 |
| 3 | 收益侵蚀 | 每发最终结算得分降低 10%。 |
| 4 | 鳞片腐蚀 | 直接撞破气泡的得分降低 15%；技能间接得分不受此项影响。 |
| 5 | 献出一鱼 | 每关少 1 次发射，至少保留 1 次；额外发射遗物仍生效。 |
| 6 | 深海献祭 | 每次发射前，随机献祭 2 颗气泡；无得分、无爆炸、无法再生。 |
| 7 | 幼体供养 | 每次成功分裂或召唤，扣除母鱼当前气泡分的 25%；达到数量上限不扣分。 |
| 8 | 返生血税 | 每次落底返弹，失去主鱼当前气泡分的 50%；回音航线也生效。 |
| 9 | 梦境遗忘 | 主鱼每发首次进入漩涡或传送门，清空其当前气泡分；之后仍可继续得分。 |
| 10 | 黑潮枯萎 | 未变成幽灵的气泡价值再降低 15%；幽灵气泡保留完整原值。 |
| 11–16 | 深渊加压 | 每层结算扣分再增加 5 个百分点，11 层扣 15%，16 层扣 40%；前十项继续生效。 |

分数扣除分别在触发时与最终结算时计算，主鱼、幼体按同一规则结算，不会重复扣除。无触发条件的负面暂时不产生损失；更换遗物种类不会换掉负面。普通遗物可补偿部分风险。关卡目标仍基于原始地图奖励，不会因负面效果降低。旧存档保留关卡、遗物、已结算分数与已用发射次数，并同步新阶梯。

## 2.0 更新

- 5 个海域、10 层下潜：日光浅滩 → 荧光海林 → 暮光裂谷 → 无光深渊 → 拉莱耶遗城。通关后可继续无尽下潜。
- 4 种布局、5 条随机航线：繁生珊瑚、珍珠矿脉、湍流航道、回音海沟、古神祭场。每次过关先选下一条航线，再挑遗物。
- 地图基础气泡数由 42 增至 90，珍珠矿脉额外增加 8 颗；单颗基础分从 10 增至 34。珍珠为 4 倍基础分，爆裂泡炸开邻近得分点。目标根据本层地图奖励及深度计算，倍率和技能会继续提高收益。
- 24 种可组合遗物，开局三选一，每轮有 3 次重抽。其中 9 种克苏鲁遗物：触须、凝视、幼体孵化、血潮献祭、幽灵再生、虚空吞口、群星仪式、梦魇和深潜者再生。
- 侵蚀度达到 1 / 3 / 6 / 9，鱼的触须、额外眼睛、古神背景、拖尾、界面配色逐级异化。负面效果按累计获得次数逐层解锁，可用普通遗物补偿部分风险。
- 新增洋流、热泉、漩涡、祭坛，保留弹簧、转轮和传送门。机关随深度逐步解锁。
- 本机自动存档、旧版进度迁移、键盘操作、可选合成音效和减少动态效果支持。

## 本地运行

需要 Node.js 18 或更高版本，无第三方依赖。

```sh
npm start
# 打开 http://127.0.0.1:4317
npm test
```

纯 HTML/CSS/Canvas/JavaScript。静态文件直接放在 main 分支根目录，GitHub Pages 使用 Deploy from a branch → main → / (root)，由 .nojekyll 保留直接静态发布。
